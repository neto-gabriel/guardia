Sobre o GuardIA

Projeto de proteção digital

🎯

Objetivo do projeto

O GuardIA é um protótipo de sistema com Inteligência Artificial criado para demonstrar como a tecnologia pode auxiliar na proteção digital de crianças e adolescentes.

O sistema analisa mensagens de uma conversa e procura identificar possíveis situações de risco, como cyberbullying, aliciamento virtual, ameaças e golpes.

A proposta é apresentar, de forma simples e educativa, como um sistema desse tipo poderia identificar sinais de atenção e orientar o usuário diante de uma situação potencialmente perigosa.

🧠

Como funciona

O funcionamento do GuardIA começa quando uma mensagem é digitada na área Conversa.

A mensagem é enviada para a API do sistema, que realiza a análise e identifica possíveis sinais relacionados às categorias de risco.

O resultado apresenta a categoria identificada, nível de risco, confiança da análise, sinais encontrados e orientação.

Quando um possível risco é detectado, o protótipo também demonstra uma notificação simulada no celular do responsável.

💻

Tecnologias utilizadas

🐍 Python + Flask Utilizados no desenvolvimento da lógica do sistema, processamento das mensagens e criação da API responsável pela análise.
🌐 HTML Responsável pela estrutura das telas, informações, componentes e organização da interface.
🎨 CSS Responsável pela identidade visual, cores, layout, cartões, animações, celular simulado e responsividade.
⚡ JavaScript Controla a interação da interface, comunicação com a API, resultados, alertas, histórico e painel.
🛡️

Sistema de proteção

O GuardIA foi pensado como uma ferramenta de apoio à segurança digital, buscando transformar a análise de mensagens em informações simples e fáceis de compreender.

Quando uma situação de risco é identificada, o sistema apresenta uma orientação educativa e demonstra como um responsável poderia ser informado sobre o ocorrido.

🧪

Protótipo acadêmico

Esta versão do GuardIA foi desenvolvida como uma demonstração acadêmica para a Feira de Ciências.

O projeto tem como objetivo demonstrar o conceito de uma ferramenta de proteção digital e apresentar como esse tipo de tecnologia poderia evoluir futuramente para uma aplicação mais completa.

⚠️ Esta versão é uma simulação educacional. As notificações apresentadas no celular são simuladas e não são enviadas para um aparelho real.
